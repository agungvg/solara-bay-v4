Solara Bay is a sun-soaked coastal open-world crime game built from scratch with three.js — drive the Strand, steal cars, dodge the Solara Bay Police, and run eight story missions for Mira Kesang and her crew.

Controls: WASD move / drive, mouse drag to look, E enter or exit a car, F shoot, 1–4 switch weapons, Z / X / C crew abilities, M missions, Esc pause. Progress, cash and rank save to localStorage.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080
```
